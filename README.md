Welcome to **OPSEN** — an integrated open-source ecosystem for power system computation, simulation, and debugging, built by Zou Dehu!

**OPSEN (Open Power System Engineering)** will continue to expand with more practical tools and applications, with the long-term goal of fully supporting power system operation planning and education.

## 📦 Project Overview

|Project|Function|Language|Status|
|------|------|------|------|
| [**ZRTDB**](https://github.com/zoudehupowersystem/ZRTDB)| Zero-copy Real-Time Data Bus | C++/Rust | 🟢 Released  |
| [**OPSEN-PowerTool**](https://github.com/zoudehupowersystem/power_tool)| Power System Utility Tools | Python | 🟢 Released |
| [**OPSEN-RAG**](https://github.com/zoudehupowersystem/OPSEN-RAG) | Power System Knowledge Q&A | Python | 🟢 Released |
| [**OPEN-MODEL**]| Power System Base Models & Topology Analysis | C++ | 🔄 Planned  |
| [**OPSEN-FLOW**] | Power Flow Calculation | C++ | 🔄 Planned |
| [**OPSEN-EMTP**] | Electromagnetic Transient Simulation | Rust | 🔄 Planned |
| [**OPSEN-SCD**](https://github.com/zoudehupowersystem/pySCD) | Substation SCD File Parser | Python | 🔄 Planned |
| [**OPSEN-GridTrace**] | Power System Communication Protocol Debugger | Rust | 🔄 Planned |




欢迎来到邹德虎建立的电力系统计算 / 仿真 / 调试的一体化开源生态！
